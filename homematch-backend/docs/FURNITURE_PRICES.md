# ราคาเฟอร์นิเจอร์ประมาณการ HomeMatch

| รายการ | ราคาต่อชิ้น (บาท) | สมมติฐาน |
|---|---:|---|
| เตียง | 15,900 | 6 ฟุตพร้อมที่นอนระดับกลาง |
| โซฟา | 12,900 | ผ้า 3 ที่นั่ง |
| โต๊ะ | 5,900 | โต๊ะทั่วไป/ทานอาหาร ไม่รวมเก้าอี้ |
| ตู้ | 8,900 | ตู้เก็บของสำเร็จรูป |

อย่างละ 1 ชิ้นรวม **80,990 บาท** ตัวอย่างเตียง 2 ชิ้นและโซฟา 1 ชิ้นรวม **44,700 บาท** ระบบคิดตามจำนวน instance ที่วางจริง

ใช้หน้าร้าน [IKEA Thailand](https://www.ikea.com/th/th/rooms/living-room/) และ [HomePro อ่างล้างหน้า](https://www.homepro.co.th/c/BAT01) ประกอบการเลือกช่วงงบ ตัวเลขข้างต้นเป็นค่าประมาณที่กำหนดเอง ไม่ใช่การคัดลอกหรืออ้างว่าเป็นราคาสินค้ารุ่นใดจากร้านเหล่านี้

## การใช้งาน

- รัน npm run seed:furniture ใน Backend เพื่อเพิ่มราคาที่ยังไม่มี
- Backend เรียก seed เดียวกันเมื่อเริ่ม server เพื่อให้ฐานข้อมูลใหม่มีราคาเริ่มต้น
- seed เป็น insert-only ไม่ทับราคา Admin, ราคา 0 หรือ null ที่ตั้งไว้แล้ว ไม่แก้ saved designs หรือ price snapshots เดิม
- แบบที่บันทึกราคาก่อนเพิ่มราคาให้เลือก “ดูราคาอ้างอิงปัจจุบัน” บนหน้าสรุปราคา แล้วบันทึกอีกครั้งเมื่อต้องการใช้ราคาใหม่
- ราคาพื้น/ผนังยังไม่ถูกเติม เพราะผู้ใช้ขอราคาเฟอร์นิเจอร์ และระบบยังไม่มีพื้นที่วัสดุจริงสำหรับคำนวณ
- Mobile แสดงราคาจาก catalog API ในรายการเลือกเฟอร์นิเจอร์ และใช้การคำนวณจาก Backend ในหน้าสรุป
